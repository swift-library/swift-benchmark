Collect resident-memory and allocation measurements for performance reports.

## Overview

Memory supplies platform-backed measurements to Report. Unsupported metrics
are reported as unavailable, so callers can distinguish missing measurements
from a measured zero.

See the [package usage guide](https://github.com/swift-library/swift-benchmark/blob/master/Documentation/UsageManual.md)
for installation and complete examples.
