Connect Swift Testing declarations to benchmark measurement.

## Overview

The benchmark trait supplies measurement configuration to supported suites
and tests. Ordinary `swift test` execution still runs each declaration as a
test; the benchmark command owns repeated measurement and reports.

See the [package usage guide](https://github.com/swift-library/swift-benchmark/blob/master/Documentation/UsageManual.md)
for installation and complete examples.
