Compare, diagnose and export performance measurements.

## Overview

Report owns structured documents, baselines, budgets, diffs, attribution and
rendering. Runtime span recording belongs to Instruments and measured
execution belongs to Benchmark.

See the [package usage guide](https://github.com/swift-library/swift-benchmark/blob/master/Documentation/UsageManual.md)
for installation and complete examples.
